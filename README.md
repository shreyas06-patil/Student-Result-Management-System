# Student Result Management System

A console-based **Student Result Management System built using Java**. The application allows users to add students, manage subject marks, search student records, display results, and find the topper based on total marks.

## Features

* Add student details and subject marks
* Display all student records
* Search students by name
* Calculate total marks
* Find the topper
* Menu-driven console interface
* Supports up to 10 students and 10 subjects per student

## Technologies Used

* Java
* Scanner
* Arrays and 2D Arrays
* Methods
* Loops
* Conditional Statements
* Switch-Case
